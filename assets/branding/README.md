# Arbejde - Tid & Løn — designforslag

Tre logo- og appikon-retninger med udgangspunkt i eksisterende mørkt design og farver fra `styles.css`.

## Koncepter
- **01 (anbefalet):** analogt ur + dansk `kr` i mintgrøn cirkel.
- **02:** geometrisk A-monogram + lønbjælker + miniklokke.
- **03:** arbejdstaske og urskive.

Logoer findes i mørk og lys version, og navigation indeholder 14 selvstændige, farvekodede SVG-ikoner.

**Kun designforslag:** Denne ændring ændrer ikke appens funktioner eller PWA-filer. PNG-filer i 192, 512 og 1024 px er udarbejdet som separat downloadpakke og skal erstatte rodens `icon-192.png` og `icon-512.png`, hvis koncept 01 vælges.

Ved integration af koncept 01 bør rodens `icon.svg`, PNG-ikoner, `manifest.webmanifest` (hvis navnet ændres) samt cacheversionen i `sw.js` opdateres samlet.
